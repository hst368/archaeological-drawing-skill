# Changelog

## 1.1.0 - 2026-05-30

- Add an explicit image-backend capability boundary for transparent-background PNGs, object/background separation, reference-image editing, and iterative revision.
- Add prompt templates for transparent layout assets, background removal/object isolation, and layered export handoff.
- Clarify that PSD or layered-source output requires a verified external toolchain and must not include AI-completed artifact detail.
- Require disclosure when object isolation, transparent-edge cleanup, or non-artifact background completion is used.
- Clarify that glare on the artifact body is high-risk evidence, not background to be removed or completed.

## 1.0.0 - 2026-04-30

- Mark the public skill package as the first store-ready release.
- Add version metadata, distribution notes, example prompt packages, and repository hygiene files.
- Keep the core archaeological drawing workflow unchanged: evidence gate, output tiers, workflow modes, and risk notes remain the behavioral contract.
